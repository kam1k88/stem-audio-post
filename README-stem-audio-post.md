# Stem Audio Post

Небольшое Windows-приложение для автоматизированного стартового сведения четырёх стемов:
`drums`, `bass`, `other`, `vocals`.

## Что делает

1. Разделяет исходный трек предобученной моделью Demucs `htdemucs_ft`.
2. Кэширует стемы отдельно для каждого исходного файла по SHA-256.
3. Проверяет, что все четыре стема существуют и читаются.
4. При необходимости приводит аудио к 44,1 кГц и стерео.
5. Применяет мягкий EQ, опциональный сайдчейн и небольшое расширение стерео барабанов.
6. Собирает микс, нормализует его к ориентиру -14 LUFS и ограничивает пиковый уровень.
7. Сохраняет WAV float 32-bit и JSON-отчёт с метриками. Из интерфейса можно экспортировать WAV float или FLAC PCM 24-bit.

## Установка

Нужен Python 3.10–3.12 и интернет для установки зависимостей/модели.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-stem-audio-post.txt
python stem-audio-post-rewritten.py
```

Если используете другой Python, замените `py -3.11` на подходящую версию.

## Важные ограничения

- Это автоматизированный стартовый микс, а не универсальный мастеринг и не замена звукорежиссёру.
- Demucs использует предобученную модель для разделения; дальнейшая обработка — обычный DSP, не генеративный ИИ.
- Настройки обработки намеренно мягкие, но всё равно могут ухудшить конкретный материал. Сравнивайте исходник и результат на одинаковой субъективной громкости.
- Цель LUFS может не достигаться после лимитера. Отчёт отдельно показывает итоговые LUFS и sample peak.
- `sample_peak_dbfs` — пиковый уровень сэмплов, а не измерение true peak.
- Кэш создаётся рядом с исходным файлом в `.stem-audio-post-cache`. Его можно удалить, чтобы освободить место; при следующем запуске Demucs выполнит разделение заново.
- Приложение не предназначено для автоматического сведения уже готовых 4/40/101 стемов из отдельного проекта без изменения кода: сейчас входом служит готовый аудиотрек, который Demucs разделяет на четыре группы.

## Выходные файлы

Для `song.wav` приложение создаёт:

- `song_mix.wav` — промежуточный мастер WAV float 32-bit;
- `song_mix.report.json` — настройки и измерения;
- `.stem-audio-post-cache/` — проверенный кэш стемов Demucs.
