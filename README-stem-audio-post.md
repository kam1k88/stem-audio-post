# Stem Audio Post

GUI-приложение для автоматизированной обработки аудио через Demucs `htdemucs_ft` и DSP-цепочку с 12 независимыми переключателями.

## Что делает

1. Принимает WAV, FLAC, MP3, M4A, OGG, AIFF.
2. Разделяет готовый трек Demucs на `drums`, `bass`, `other`, `vocals`.
3. Проверяет и синхронизирует стемы, приводит их к 44,1 кГц и стерео.
4. Позволяет включать и отключать каждый из 12 блоков обработки:
   - бас: SUB/BODY/TOP, EQ и компрессия;
   - гармоники и атака баса;
   - punch/EQ/сатурация ударных;
   - EQ и компрессия вокала;
   - EQ инструментов;
   - вокал → инструменты (ducking);
   - бочка → бас (ducking);
   - расширение стерео ударных;
   - моно-низ до 120 Гц;
   - расширение высокочастотной Side-составляющей;
   - параллельная компрессия;
   - мастер-EQ и лимитер.
5. Показывает метрики после анализа. Автоматически не экспортирует файл в папку с исходником.
6. По нажатию «Экспортировать…» предлагает MP3 320 kbps, WAV PCM 24-bit или FLAC PCM 24-bit.
7. Сохраняет отчёт JSON и промежуточный предпросмотр в `%USERPROFILE%\\.stem_audio_post\\preview`.

## Установка

Рекомендуется Python 3.11.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-stem-audio-post.txt
python stem-audio-post-rewritten.py
```

Demucs при первом использовании скачает модель `htdemucs_ft`; для этого нужен интернет. Установите FFmpeg и добавьте его в `PATH`, если нужен экспорт MP3. WAV и FLAC экспортируются через SoundFile.

## Важные ограничения

- Это автоматизированная цепочка DSP, а не гарантия профессионального мастеринга. Всегда сравнивайте результат с исходником на согласованной громкости.
- Некоторые параметры намеренно умеренные и регулируемые. Включение всех эффектов не обязательно улучшит любой трек.
- Harmonies/PitchShift использует `pedalboard.PitchShift`, если он доступен в установленной версии; если нет, приложение сообщает об этом и пропускает только этот подблок.
- В отчёте `sample_peak_dbfs` — пик сэмплов, не true peak. Лимитер не заменяет отдельную проверку true peak.
- Входной готовый трек разделяется Demucs. Программа не импортирует напрямую уже подготовленный набор из 101 отдельных стемов.
